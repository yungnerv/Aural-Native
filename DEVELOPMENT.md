# Development

Use the Swift files in `Aural/Models`, `Aural/Playback` and `Aural/Views` to make focused changes. Increment `VERSION` for releases. `project.yml` defines the XcodeGen project (iOS 26.1+). Pull requests and app changes on main run CI. The build compiles the portable model tests and then the iOS app without signing, verifies bundle identity and version, and produces a versioned IPA and checksum. To publish a persistent prerelease, manually run Build Aural Native on main and enable Publish release. The unsigned IPA must be signed separately on your device. Keep bundle identifier `local.aural.player` unchanged for continuity. Public repository: never commit personal music, passwords, certificates, provisioning profiles or signing secrets. Physical-device testing, extended audio decoding and full PWA feature parity remain outstanding. The first build must pass before merging; do not replace your known-good IPA until device testing succeeds.
